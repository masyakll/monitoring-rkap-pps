DATA DEMO - MONITORING RKAP PPS

Seluruh 15 pekerjaan, progres milestone, anggaran, nilai GR, prognosa, penyebab, dan quick win dalam folder ini adalah DATA SIMULASI.
Data tidak boleh dianggap sebagai angka atau status aktual perusahaan dan tidak boleh dipakai untuk laporan resmi.

Folder data/ (state asli project) tidak diubah oleh paket ini.
Akun pengguna dan hash kata sandi disalin dari state project yang dikirim agar nama akun PIC tetap tersedia.
Sesi login lama sengaja dikosongkan sehingga pengguna harus login ulang. Gunakan username dan kata sandi yang sama seperti pada project lokal sebelumnya.

Untuk mengaktifkan dataset ini, tambahkan DATA_SOURCE=dummy dan DATA_DIR=./data-demo pada file .env di root project.
Untuk kembali menggunakan data lama, kosongkan atau hapus DATA_DIR dari .env, lalu restart server.
