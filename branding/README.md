# Aset branding

- `logo.png`, `logo.jpg`, `logo.jpeg`, atau `logo.webp`: logo perusahaan.
- `background.png`, `background.jpg`, `background.jpeg`, atau `background.webp`: foto perusahaan untuk panel login (opsional).

Paket review tidak menyertakan gambar latar ilustratif bawaan. Jika ingin memakai foto, gunakan foto fasilitas/kantor yang memang diizinkan perusahaan dan letakkan file dengan nama `background` serta ekstensi yang didukung. Jangan memakai gambar atau data internal yang tidak memiliki izin untuk dibagikan.
